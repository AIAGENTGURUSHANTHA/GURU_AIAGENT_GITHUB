# Data Science

Data Science is a process of extracting useful insights and knowledge from data.

# Stages for Data Science

DATA -> is a piece of information in Raw format, not ready to perform operations
 |
Data Collection
 |
Data Cleaning -> remove malicious info, missing values, redundant data
 |
Exploratory Data Analysis
 |
Statistical Analysis -> Numerical data, mean, mode, median
 |
Machine Learning Models -> train the data based on the models -> See accuracy, precision -> select model
 | 
Predictions -> get the prediction based on trained data, why we need (To make the business decision)
 |
Business Decisions
